# VN ERP/MES → CMS API 인터페이스 개발 진행현황

> 최종 갱신: 2026-08-11
> 범위: **VN(DWCMSTEST) 우선**. HQ(도우제조원가시스템)는 추후.
> 목적: 기존 **엑셀 수기 업로드**를 **API 연계(화면 [API 호출])** 로 대체. (`InterFace_정의서_ver1.8.xlsx` 기반)

---

## 1. 아키텍처
```
[화면 [API 호출]]
      │  POST /api/iface/fetch
      ▼
[백엔드 오케스트레이션]  IfController → IfService
      │           ├─ ErpApiClient (영림원, cert + 중첩 ROOT/DataBlock1)
      │           └─ MesApiClient (미라콤, 단순 JSON / data.rows)
      ▼
[적재 프로시저]  UP_VN_IF_LOAD_*  (OPENJSON 파싱)
      ▼
[스테이징 테이블]  DOI_VN_IF_*  (API 원형 + RAW_JSON 보관)
      ▼
[다운스트림 변환]  UP_VN_IF_XFORM_*  (멱등 delete-insert, API 원문 저장)
      ▼
[운영 테이블]  doi_dept_cost, doi_vn_material 등 → 기존 원가 계산에 반영
```

- **소스**: ERP=영림원 K-System(`172.16.21.32:8801` TEST / `:8800` 운영, cert 인증). MES=미라콤 EMI(`172.16.23.30:8888`, 인증 불필요).
- **인증정보**(certId/certKey/dsnOper/dsnBis): 코드/깃에 없음. `application.yml` 환경변수 플레이스홀더로 외부화 → 서버 env 주입.

## 4. 계층별 상세

### 4.1 스테이징 테이블 (18종)
- 공통: `SITE, LOAD_DTTM, REQUEST_ID` (+트랜잭션은 `SEL_CODE`) + API 필드 + `RAW_JSON NVARCHAR(MAX)`(원본 보관).
- 마스터 5종 + 트랜잭션/조회 13종.

### 4.2 적재 프로시저 (18종)
- 패턴: `@json, (@selCode,) @requestId` → `DELETE(SITE=VN, SEL_CODE)` → `OPENJSON` INSERT → `@@ROWCOUNT` 반환. **멱등**.
- 파싱 경로: ERP=`$.DataBlock1`, MES=`$.data.rows`.

### 4.3 백엔드 (`com.dowinsys.cost.common.iface`)
- `IfEndpoint`: 18종 레지스트리(소스·엔드포인트경로·적재프로시저·selCode여부).
- `ErpApiClient`/`MesApiClient`: HTTP 호출. 인증정보는 `IfProperties`(env 외부화).
- `IfService`/`IfController`: `POST /api/iface/fetch`(호출→적재→건수), `GET /api/iface/status`(설정/cert 주입 확인, 비밀값 미노출).

### 4.4 프론트 (`[API 호출]` 버튼)
- 재사용 헬퍼 `axios.api.iface()` + `ifaceApiMixin`(호출·토스트·새로고침·에러 공통).
- 6화면 배선: C0007001/002/009 + C0007005(TAB070003/004) + C0007003(TAB070013).
- **노출 게이트**: 평소 숨김, 테스터만 `localStorage.setItem('IF_API_TEST','1')` 로 노출(VN 사업장).

### 4.5 다운스트림 변환 (5/6)
- 표준: 멱등 delete-insert(`site·yyyymm·sel_code`) + **API 원문 그대로 저장** + 미매핑 컬럼 NULL(보류).
- 생성기 `scripts/gen_xform.py`(대량 컬럼 매핑 오류 방지).
- 완료: DEPT_COST, STOCK_DETAIL, EXP_SALES, ETC_INOUT, MATERIAL(92컬럼).

## 5. 주요 결정사항
1. **접두 `DOI_VN_IF_`**, **VN 전용 테이블 신규 생성**(기존 재사용 불가).
2. **적재 방식(Method B)**: 필요한 컬럼 + `RAW_JSON` 원본 병행 보관.
3. **변환 매핑 = API 원문 그대로 저장** (계정과목=베트남어, 비용구분=SG&A 등). 기존 한글과 표기 불일치하나 원문 유지. *(사용자 확정)*
4. **미제공 컬럼(코스트센터분류/유형/제외여부 등)은 보류(NULL)**. *(사용자 확정)*
5. **인증정보 외부화**: cert는 코드/깃 금지, 서버 환경변수만.
6. **메뉴 IA**: 최상위 「타시스템」 유지, 마스터는 「원가기준정보」 그룹.
7. **변환 자동화**: 현재 [API 호출]은 적재까지만. 운영 반영은 별도(수동 EXEC 또는 [원가 반영] 버튼) — *보류*.
