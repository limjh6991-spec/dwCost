# 비나(VN) 재공평가 신규포맷 재설계 (260801)

## 목표
재공평가를 신규 MES 포맷(doi_vn_prod_resc / doi_vn_cost, 포지션 LINE·B_LEVEL × WIP·FGS × PL전50%/후90%) 기준으로 재작성.
현업 정의 로직 ④(재공단가 ETC-IN/OUT 포함)·⑤(포지션별 평가) 반영.

## 데이터 소스
| 항목 | 소스 |
|---|---|
| 재공 수불수량(BOH/IN/OUT/LOSS/EOH, 포지션·전/후) | **doi_vn_prod_resc** (DOI_PROD_SUBUL 대체) |
| 재공기초 금액(원가항목별) | **doi_cost_boh** (도우코드 레벨, T_BOH수량과 61/61 일치 검증) |
| 투입 금액(재료/가공) | doi_expn_matl |
| ETC-IN(R/S·R/W) 금액 | **DOI_VN_RSRW** (제품 기초단가, R/S우선·한도) |
| 면적 | DOI_MODEL_MAST |
| 출력(포지션×수량/금액) | **doi_vn_cost** / (원가항목별) DOI_COST |

## 핵심 공식 (현업 기본 배부로직 — 반드시 반영)
1. **생산환산량** = (PL전 수량 × 50%) + (PL후 수량 × 90%)   *(현재 배부용 환산량=(IN+OUT+LOSS)/2 → 이 식으로 변경)*
2. **배부적수** = 생산환산량 × 모델별 면적
3. **배부비율** = 모델별 배부적수 / 당월 총 배부적수
4. **재공품 단가** = (BOH + IN + ETC-IN) 금액 / [OUT + ETC-OUT + (PL전×50%) + (PL후×90%)] 수량
   - 현재 대비 **분자에 ETC-IN, 분모에 ETC-OUT 추가** (기존은 (BOH+IN)/(OUT+EOHEQ))
   - ⚠️ 현업 시트 분자 표기는 "EOH+IN+ETC-IN"이나, 가중평균·원가보존상 분자는 **기초(BOH)** 여야 정합(제품단가 6번도 BOH). → **BOH로 해석** (확인 요)
5. **재공재고 금액** = 재공품 단가 × Σ(포지션별 수량 × 포지션별 평가비율)   *(LINE_WIP/FGS·B_WIP/FGS × PL전50%/후90%)*
6. **제품 단가** = (BOH + IN + ETC_IN) 금액 / (BOH + IN + ETC_IN) 수량   *(현재 일치 — 유지)*

- **재공기초 분할** = doi_cost_boh 원가항목 금액 × (포지션 수량 / T_BOH 총수량) → 포지션 배분 (총액 보존)

## 이중 출력
- **DOI_COST** (원가항목=재료/가공 유지) — 원가명세서·매출원가 연계용 (기존 하류 호환)
- **doi_vn_cost** (포지션별 수량/금액) — 신규포맷 재고/증빙용

## 특이 처리
- R&D 8개(716NT·818M 등): 재공기초 수량만 있고 doi_cost_boh 금액 없음 → **기초금액 0** (총 기초금액은 전부 보존)
- 신규 CONV = EOHEQ + OUTETC − 타계정입고 (V_VN_WIP_CONV에 이미 존재) → 재공단가 분모에 활용 검토

## 구현 순서
1. **재공기초 분할** — doi_cost_boh 금액 → 포지션(수량비). (도우코드 레벨 이미 정합)
2. **재공단가** — ④ 공식 (ETC-IN=DOI_VN_RSRW, ETC-OUT=doi_vn_prod_resc 기타출고, EOHEQ). 원가항목별.
3. **재공평가(EOH)** — ⑤ 포지션별 평가 → doi_vn_cost + DOI_COST.
4. 하류(제품수불/매출원가) 연계 검증.
5. 재고평가 R/S·R/W 차감(제품 기초).

각 단계 구 vs 신 대사 + 원가보존 검증.
