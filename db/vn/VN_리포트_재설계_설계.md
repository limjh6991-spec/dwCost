# 비나(VN) 원가 리포트 재설계 설계서 (260801)

## 배경 / 문제
결산증빙자료(C0008000)·원가레포트(C0009000)의 일부 리포트가 리팩토링으로 폐기된 구 테이블
`doi_mat_cost`·`doi_expen_matl`을 참조. 구 테이블은 신 배치(08-01)에 없어 향후 드리프트 위험.
근본 원인: **HQ는 BOM 기반 배부, VN은 직과+면적 배부**로 원가구조가 달라, HQ 리포트 컬럼(소요량·BOM배부율)이
VN에는 항상 무의미. → VN 전용 화면 필요(본사와 분리).

## VN 원가 데이터 모델 (신 파이프라인, 전부 확보)
| 원가 | VN 배부 | 신 소스 |
|---|---|---|
| 직접재료비 | 직과 | doi_expn_matl(배부방식='직과', 항목=자재번호, 투입금액) |
| 간접재료비 | 공통(면적) | doi_expn_matl(공통) + DOI_MODEL_MAST(면적 XY) |
| 가공비 | 면적 | DOI_COST(투입·환산량 ADJ_QTY) + DOI_MODEL_MAST(면적 XY) |
| 재공·단가 | 재공평가 | DOI_COST / DOI_COST_BOH / doi_cost_unit |

- **배부율 = 환산량×면적 / Σ(환산량×면적)** — 실제 배부와 일치 검증(오차 0.000004).
- 재료 직과는 배부율/소요량 N/A(직접 귀속) — 정상.
- 총액·제품별 detail: 구 테이블과 0 불일치(이미 검증).

## 6개 리포트 재설계
| 리포트 | VN 화면 표시 | 신 소스 | 분리 방식 |
|---|---|---|---|
| 제품별 투입비용 (C0008004) | 제품별 직접재료/간접재료/가공 + 단가 | DOI_COST 단일 | 쿼리 `<choose site>` |
| 제품별 가공비 (C0008015) | 제품별 가공·면적·환산량·배부율 | DOI_COST + DOI_MODEL_MAST | VN 탭/쿼리 |
| 원가항목별 재료비 (C0008006) | 자재별 직과/공통·면적·배부율 | doi_expn_matl + DOI_MODEL_MAST | VN 탭 |
| 제품별 투입재료비 (C0008007) | 제품×자재 직과/공통 | doi_expn_matl | VN 탭 |
| 제조경비 집계표 (C0009005) | 제품별 경비(면적배부) | doi_acct_expen + DOI_COST | VN 프로시저 내부 교체 |
| 재료비 배부표 (C0009006) | 제품별 재료 배부 | doi_expn_matl + doi_matl_resc | VN 프로시저 내부 교체 |

## 분리 아키텍처 (기존 패턴 활용)
1. 쿼리 dispatch `<choose><when site='VN'>` — 컬럼 동일, 소스만 VN.
2. VN 전용 프로시저 — C0009005/6은 이미 `VN_...ByModel` 존재 → 내부 SELECT만 신 테이블로.
3. VN 전용 탭 — 컬럼 상이 리포트는 auth-tabs로 VN 탭 신설 + VN 그리드/쿼리(C0003001/2 패턴).

## 실행 순서
1. **C0009005·C0009006 VN 프로시저 재작성**(구조 유지·소스만 신 테이블) — 최안전, HQ 무영향.
2. **C0008004 VN 쿼리 분기**(DOI_COST 단일) — <choose>, HQ 그대로.
3. **C0008015/C0008006/C0008007 VN 전용 탭 신설** — 직과/면적 컬럼 + VN 쿼리. HQ 탭 유지.

각 단계 구 vs 신 대사 검증.

## 실행 결과 (260801 완료)
전 6개 리포트 VN 분기 완료. **구 doi_mat_cost/doi_expen_matl 의존 제거**(VN). HQ는 원본 유지.

| 리포트 | 구현 | 검증 |
|---|---|---|
| 제조경비 집계표 (C0009005) | VN_ManufacturingExpenseByModel 프로시저 소스 교체(doi_expn_matl) + _Col `<choose>` | 구 vs 신 출력 34컬럼·55행 완전일치 |
| 재료비 배부표 (C0009006) | VN_DsitributeMatCostByModel 소스 교체 + _Col `<choose>` | 67컬럼·44행 완전일치 |
| 제품별 투입비용 (C0008004) | Sch1/Sch2 `<choose site=VN>` → DOI_COST 단일 | Sch1 금액 66/66, Sch2 총 7,097,054 |
| 제품별 가공비 (C0008015) | Sch1 `<choose>` → DOI_COST+DOI_MODEL_MAST(면적·배부율) | 가공 1,972,637, 배부율합=1 |
| 원가항목별 재료비 (C0008006) | Sch1 `<choose>` → doi_expn_matl+면적. 직과 소요량/배부율 N/A, 공통 면적배부 | 재료 5,124,416(직과4,873,250+공통251,166) |
| 제품별 투입재료비 (C0008007) | Sch1(요약)/Sch2(상세) `<choose>` | 5,124,416 |

**구현 방식**: 별도 VN 탭 신설 대신 **기존 그리드 재사용 + `<choose site=VN>` 쿼리 분기**로 처리.
- 가공비: 전 컬럼(면적·배부율 포함) VN 적용 → 빈 컬럼 없음.
- 재료 배부상세: 직과행은 소요량/배부율 빈칸(=직과라 당연), 공통행만 면적배부율 표시.
- 배부율 재구성 = 환산량×면적/Σ(환산량×면적) [오차 0.000004 검증].
