# 202608 재고원가 결함 C — 양산측 반품 크레딧

작성 2026-09-11 / 대상 DB: 도우제조원가시스템 (10.100.40.17,14233)
배포 파일: **`UP_DOI_STOCK_COST_fix260911c.sql`** (A·B `fix260911` 위에 C 추가, 백업 `_bak260911c.sql`)

## 결함 (C)

담당자 특이사항 ③: "최초는 양산(P모델)의 출고가 −가 되어 재고가 증가하는 구조로 발생되며,
그 이후 P → R로 품목을 대체한다."

반품된 P모델의 원가가 **매출원가에서 차감(크레딧)** 되고, 그 물량이 RMA 창고로 이동해야 한다.
이 처리를 `UP_DOI_STOCK_BOH` STEP6(L884~942, `양산 OUTETC_AMT = DOI_STOCK.RMA_AMT`)가 하려 했으나,
STEP6가 STOCK_COST 재생성에 덮이는 죽은 코드라 **전 기간 미반영**이었다. 202608 양산 8개 모델의
`OUTETC_AMT = 0` (반품 크레딧 없음).

---

## 202601 선례 (권위 기준)

202601은 RMA 최초월이자 수동보정본(`DOI_STCO_202601`, 라이브와 일치). 처리 방식:

- **RMA 구분 행**: 반품 물량을 `EOH/EOH_AMT`로 RMA 창고에 재고 보유 (합 326,471,803).
- **양산 구분 행**: 각 모델의 `OUTETC_AMT = 그 모델의 반품금액`. 10모델 전부
  「양산 OUTETC_AMT == RMA EOH_AMT」 정확 일치.
- 최종 매출원가(DOI_SLCO): 반품이 판매를 초과한 모델은 **음수**
  (810P −113,020,762 / 8136 −63,197,549). 이게 "P출고 −" 효과다.

매출원가 산식(`UP_DOI_SALE_COST` L208): **`OUT_AMT − OUTETC_AMT + OUT_RMA_AMT`**.
202601은 구 산식(`OUT_AMT − OUTETC_AMT`)으로 계산돼 `OUTETC_AMT = 반품금액`이 그대로 크레딧됐다.
현 산식(+OUT_RMA_AMT, 2026-07-31 추가)에서는 **OUTETC_AMT만 세팅하고 OUT_RMA_AMT는 0으로 둬야**
같은 크레딧이 된다(둘 다 세팅하면 −OUTETC +OUT_RMA 로 상쇄되어 크레딧이 사라짐).

## 수정

`UP_DOI_STOCK_COST` COMMIT 직전에 UPDATE 추가 (647 → 678줄):

```sql
;WITH rma_stock_sum AS (   -- 모델별 RMA_AMT SUM (8136 R행 2개 dedup)
    SELECT yyyymm, sel_code, site, model, SUM(ISNULL(rma_amt,0)) AS rma_amt
    FROM doi_stock
    WHERE yyyymm=@YYYYMM AND sel_code=@SEL_CODE AND site=@SITE AND model_type LIKE '%R'
    GROUP BY yyyymm, sel_code, site, model
    HAVING SUM(ISNULL(rma_amt,0)) <> 0
),
yang_rn AS (               -- 양산행 중 모델당 1행 선택
    SELECT s.model, s.expen_sel, s.acct_name,
           ROW_NUMBER() OVER (PARTITION BY s.model ORDER BY s.expen_sel, s.acct_name) AS rn
    FROM DOI_STCO s
    WHERE s.yyyymm=@YYYYMM AND s.sel_code=@SEL_CODE AND s.site=@SITE AND s.구분=N'양산'
      AND EXISTS (SELECT 1 FROM rma_stock_sum r WHERE r.model=s.model)
)
UPDATE t SET OUTETC_AMT = r.rma_amt
FROM DOI_STCO t
JOIN yang_rn y ON t.model=y.model AND t.expen_sel=y.expen_sel AND t.acct_name=y.acct_name AND y.rn=1
JOIN rma_stock_sum r ON t.yyyymm=r.yyyymm AND ... AND t.model=r.model
WHERE t.yyyymm=@YYYYMM AND ... AND t.구분=N'양산';
```

- 모델당 1행(rn=1)에만 `OUTETC_AMT = RMA_AMT`. SALE_COST가 model+expen_sel 로 GROUP·합산하므로
  한 행에 넣어도 모델 총 매출원가에서 크레딧된다.
- `OUT_RMA_AMT`는 손대지 않음(0 유지) — SALE_COST 상쇄 방지.
- 8136 R행 2개(완제품 8,189,758 / 현장 0)는 `rma_stock_sum` 의 SUM 으로 8,189,758 확정.
