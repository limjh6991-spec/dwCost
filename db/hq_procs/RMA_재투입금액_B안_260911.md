## 고친 문제

STEP 9 는 **작성 이후 한 번도 행을 만든 적이 없는 코드**다.
`DOI_PROD_SUBUL.기타입고_RMA_RW <> 0` 인 달이 전 기간에서 202608 하나뿐이라
202601~202607 에는 0행 INSERT 였다. 그래서 아래 결함들이 발견되지 않은 채 남아 있었다.

1. **금액이 리터럴 0** — `0 AS boh, 0 AS [in]` (구 L737~738).
   재료비 쪽은 `UP_DOI_MAT_AMT` 의 `품목자산분류 <> N'제품'` 으로 제외되므로,
   양쪽 모두 0 이면 **8,146,083 이 어디에도 안 들어가고 7073P 재공품 원가에서 통째로 누락**된다.
2. **단가 원천 월이 하드코딩** — `WHERE s.YYYYMM = '202512'` (구 L657).
   `DOI_STCO` 에 `구분='RMA'` 는 202601~202607 에만 있고 202512 에는 없다(개발 38/양산 7).
   즉 폴백 단가가 항상 0 이었다. 202601 개발 시점의 전월을 박아둔 흔적으로 보인다.
3. (별건, 이미 배포됨) `EXPEN_SEL명='RMA_RW'` 가 ASCII 6자라 L896 패딩식이 NULL 을 만들어
   515 를 일으키던 문제 → `execlog_NULL_515_원인과수정260911.md` 참조.

### 조인키 근거 — `품번 = MODEL + 'R'`

`ETC_IN_RMA_QTY.MODEL` 은 `LEFT(도우코드,4)` 이다. R-모델 규약이 전 기간에서 1:1로 성립한다.

```
DOI_STCO 구분='RMA' MODEL     : 7073 7110 8040 8085 8091 810P 8122 8136 8140 902K
DOI_MATL_RESC 품번 LIKE '%R'  : 7073R 7110R 8040R 8085R 8091R 810PR 8122R 8136R 8140R 902KR
```

`품목자산분류='제품'` 이면서 `투입금액<>0` 인 행은 202608 에 **7073R 하나뿐**이다
(다른 '제품' 행들은 판매 출고만 있고 투입금액 0 이라 CTE 에서 제외된다).

### 금액의 종착지

`UP_DOI_COST` 본체는 `from doi_expen_matl ... and len(model) <= 5` 로 읽는다.
MODEL='7073'(4자)이므로 통과하여 `DOI_COST` 행이 된다.
EOH 산식(`UP_DOI_COST` L336~338)에서 RMA 행은
`out_qty+bad_qty+transfer_qty = 0 AND loss_qty(253) > 0 AND eoh_qty(544) <> 0` 으로
**세 번째 분기**를 타므로 `eoh = boh + [in] = 8,146,083` — 전액이 재공 EOH 에 남는다.
수량 정합: `BOH 539 + 재투입 258 − LOSS 253 = EOH 544` ✓

## 남은 확인 사항

1. **명칭 규약 불일치** — 제품재고 체계(`DOI_STCO`/`DOI_STUC`)는
   `expen_sel='RMA1' / expen_sel명='RMA1' / acct_name='RMA1'` 을 쓰는데,
   STEP9 는 `RMA1 / RMA_RW / RMA_RW` 를 쓴다. 서로 다른 테이블이라 당장 충돌은 없지만
   (`UP_DOI_STOCK_COST` L246·L285 의 `ACCT_NAME=N'RMA1'` 필터는 `DOI_STUC` 대상),
   리포트에서 'RMA_RW' 로 표시되는 것이 의도인지 확인이 필요하다. 이번 수정에서는 손대지 않았다.
2. **출고측 금액** — `DOI_STOCK` 7073R 의 `OUT_ETC=258 / 공정재투입=258` 에 금액을 매기는 주체가
   `UP_DOI_STOCK_COST` 인지, 그 금액이 8,146,083 과 같아지는지 결산 후 대사 필요.
   입고측(재공)과 출고측(제품재고)이 다르면 재고가 새거나 부풀어오른다.
3. **RMA 반품 금액** — `DOI_STOCK` 7073R `RMA_AMT=3,565,861` 과
   `DOI_MATL_RESC` 7073P `기타출고금액 1,877,365` 의 차이 1,688,496 의 성격
   (담당자: "최근 매출원가를 활용해 직접 계산") 확인 필요. 특이사항 3번 검증에서 다룬다.
