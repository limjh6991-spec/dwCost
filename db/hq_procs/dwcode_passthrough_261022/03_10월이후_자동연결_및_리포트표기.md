# Phase 3·4 — 10월~ 결산 시 자동 채움 + 리포트 표기

## Phase 3 — 10월~ 결산 시 자동 채움 (방법 ② 확정)
**COST·STOCK_COST = 프로시저 인라인(결산이 직접 채움), 판관비(SLCO·SMCE) = 결산 끝 fill.** 둘 다 결산 시 자동·값 불변.

### ① 인라인 (UP_DOI_COST, UP_DOI_STOCK_COST) → `04_inline_UP_DOI_COST_STOCK_COST.md`
- 라이브 정의에 검증된 find/replace(COST 6·STOCK_COST 5) 적용 후 ALTER. MODEL(도우모델) 그레인·산식 불변, INSERT 시 `도우코드` 직접 적재.
- 결과: DOI_COST 100% / DOI_STCO 99%(main 수불행). STCO 재공LOSS 1%는 ②에서 폴백.

### ② 판관비 fill (UP_DOI_SALE_COST 직후)
- UP_DOI_SALE_COST는 깊은 윈도우배부+위치기반 INSERT 2개라 인라인 취약(silent NULL) → **결산 끝 `EXEC UP_DOI_FILL_DWCODE`** 로 DOI_SLCO·DOI_SMCE_COST(+STCO 재공LOSS 폴백) 채움.
- 결산 순서 `… → UP_DOI_STOCK_COST(인라인) → UP_DOI_SALE_COST → UP_DOI_SCOF` **다음에**:
  ```sql
  EXEC dbo.UP_DOI_FILL_DWCODE @YYYYMM, @SITE, @SEL_CODE;
  ```
  - COST/STCO는 인라인이 이미 채웠으므로 이 호출은 SLCO·SMCE·STCO폴백이 주목적(COST/STCO는 멱등 재확인, 무해).
  - 배치: 결산 스크립트 마지막 1줄(권장) 또는 UP_DOI_SALE_COST 끝에 임베드.
- 값 중립: 도우코드 컬럼만 UPDATE → 그레인·배부·이월·총액 불변(개발 202609 실증).

### 과거월(1~9월)
프로시저 재실행 불가(마감) → `UP_DOI_FILL_DWCODE` 로 4테이블 일괄 백필(02_backfill). 인라인은 10월~만.

## Phase 4 — 리포트 프로시저 표기 (ALTER만, 재결산 불필요)
대상: `DOI_PL_ByModel`, `DOI_TotalCost_Tree`, `DOI_ProductCOGS`, `DOI_ManufacturingExpenseByModel(+세목)`, `DOI_SalesAdminByModel(+세목)`, `DOI_VariableCostByModel`, `DOI_ProdSubulMonthlyReport`, `DOI_AnnualReportBySale` 등.

규칙:
- 모델 **표시 라벨**만 `COALESCE(NULLIF(도우코드,''), 도우모델)` 로 교체.
- ★ **코드값을 GROUP BY/PIVOT 키로 쓰지 말 것.** 키는 기존 `(구분,도우모델)` 유지 → 모델 split·총액 변동 방지.
  - 행라벨 리포트(ProductCOGS 등): 최종 SELECT의 모델 라벨만 교체(조인·정렬 키는 기존 유지).
  - 피벗 리포트(PL_ByModel/TotalCost_Tree): 피벗 **키는 유지**, 출력 **별칭만** 도우코드로(개발 PoC: col_label + @PivotColumns 별칭 교체 = 총액 불변 실증).
- 매퍼 동적 피벗(C0009005 `_Col` display_name / C0009008 / C0009006): display_name만 도우코드로, PIVOT 키 유지. **jar 재빌드** 수반.
- ★ C0007011 생산수불 검산: 표기만 도우코드, **역산 조인은 도우모델 유지**(MES LOT 접두 매칭 깨짐 방지).
