## 2. 원인 — 두 종류의 문제가 섞여 있다

### (A) 7~10번 : 구분이 '양산' 이라 카세트가 양산에 묻혀 있다

`doi_stco` / `doi_mat_cost` / `doi_expen_matl` / `doi_smce_cost` 의 카세트 행은 **구분='양산'**,
모델은 **VN034P1~P3**. 그래서 장표에서 양산 열/양산 합계에 섞여 나온다.

> 참고: `UP_DOI_STOCK_COST` 에는 `CASE WHEN model like 'VINA%' THEN '카세트' ELSE 구분 END` 이 있으나
> 8월 `12_FIX_카세트_MODEL.sql` 로 MODEL 을 품번(VN034P*)으로 정정한 뒤로는 이 조건이 걸리지 않는다.

엑셀 `6.제조경비집계표` 변경 전/후로 확인되는 값 (재료비):
양산 594,288,603 → **593,350,482 + 카세트 938,121**. 총액 불변, 양산에서 카세트만큼 빠진다.

### (B) 11~12번 : 매출↔재고평가 매칭 키가 어긋나 카세트 원가가 통째로 누락돼 있다

`총원가` / `제품별 손익계산서` 의 열 목록(`#MODEL`)은 **매출원장의 '품명' + 구분='카세트'** 로 만든다
(`SALES_RAW`: `WHEN 품번 LIKE 'VN%' THEN N'카세트'`, `A.품명 AS model`).
반면 원가(재고평가) 테이블은 **모델코드(VN034P*) + 구분='양산'** 이라 조인이 성립하지 않는다.
품명은 자유 텍스트라 카세트는 `VINA N_OPPO 하단틀` 같은 한글 품목명이 들어온다.

→ 카세트가 양산에 잘못 들어간 게 아니라 **리포트에서 빠져 있다**.
엑셀 `6.제품별손익계산서` II.매출원가 총합계 3,857,660,720 = 양산 3,469,279,219 + 개발 388,189,501 + 카세트 **0** + 회계 192,000 (정확히 합치함).

> **영향**: 고치면 카세트 원가만큼 **총합계 매출원가·총원가가 늘고 영업이익이 준다.** 이는 정상이다
> (지금까지 누락된 원가가 붙는 것). 양산 합계는 (A)와 달리 줄지 않는다.

## 3. 적용 방식

모두 **리포트 SELECT 전용**이다. 결산 테이블은 건드리지 않으므로 **재결산 불필요**, 과거 월도 조회 즉시 반영된다.

| 구분 | 방식 |
|---|---|
| (A) 7~10번 | 구분 재분류: `LEFT(model,2) = N'VN'` → `N'카세트'` (기존 `DOI_TotalCost_Tree` 규칙과 동일) |
| (B) 11~12번 | **매칭키를 품명 → 품번 기준으로 변경**(담당자 지시 2026-09-16) + 원가 쪽 구분 재분류 |

### (B) 매칭키 규칙 — `#SALEKEY`

품번은 대개 `모델코드 + 구분접미(P=양산 / D=개발 / T)` 인데 접미가 없는 품번도 있다.
그래서 **무조건 1자를 떼면 `818VT` 가 `818V` 에 잘못 붙는다**(둘 다 실재 모델).

```
① 품번이 당월 재고평가 MODEL 에 있으면          → 품번          (818VT, VN034P1~P3)
② 접미 1자를 뗀 값이 MODEL 에 있으면            → 그 값          (8136P→8136 등 일반)
③ 둘 다 아니면                                  → 품명          (상품 등 재고평가가 없는 건)
```

2026년 1~8월 전수 확인 결과(매출 품번 기준):

| 유형 | 건수 | 품번=MODEL | 절삭=MODEL | 적용 규칙 |
|---|--:|:--:|:--:|---|
| 일반(0310D, 7073P, 810PP …) | 대부분 | ✗ | ✓ | ② — 결과가 기존 품명과 동일 |
| `818VT` | 1 | ✓ | ✓ | ① — 절삭 금지(818V 와 분리 유지) |
| 카세트 `VN034P1~P3` | 3 | ✓ | ✗ | ① — **이번에 새로 붙는 건** |
| 상품 `DWA0900300`, `DWE15P1J00` | 2 | ✗ | ✗ | ③ — 제품 재고평가가 없는 상품, 기존과 동일 |

즉 **카세트만 새로 매칭되고 나머지는 기존 결과 그대로**다(검증 6-4 에서 확인).

상품 2건은 규칙 ③ 으로 품명을 그대로 쓴다. 즉 카세트 외에는 결과가 바뀌지 않았다.

### 6-5. 카세트 매출원가가 당기총제조원가(24,170,590)보다 큰 이유 — 정상

```
재공(DOI_COST)  기초 49,812,989 + 당월투입 24,170,590 = 완성 73,983,579, 기말 0
제품(DOI_STCO)  기초  5,740,787 +     입고 73,983,579 − 기말 705,360 = 매출원가 79,019,006
```
카세트 재공 기초재고가 커서 당월에 전량 완성·출하됐다. 수치가 완전히 맞아떨어진다.

## 8. 담당자 확인이 필요한 잔여 사항

1. **카세트 판관비 배부가 0** — `doi_smce_cost` 에 VN 모델 행 자체가 없다(202608 기준 양산 10 + 개발 15 모델뿐).
   판관비 배부는 제품별 매출비중 기준인데 카세트는 매출 139,498,299(전체의 약 1.8%)이 있으므로
   원래대로면 약 22백만원이 배부돼야 한다. 엑셀 '변경 후' 도 카세트 판관비를 전부 0 으로 그려 놨으므로
   이번 변경에서는 건드리지 않았다. 배부 자체를 살릴지는 **결산 로직(배부) 문제**로 별도 확인이 필요하다.
   배부가 생기면 카세트 열·합계는 자동으로 채워진다.
2. **총합계 증가** — 총원가·손익계산서의 총합계 매출원가가 79,019,006 늘고 영업이익이 그만큼 준다.
   그동안 리포트에서 빠져 있던 원가가 붙는 것이라 정상이지만, 월 보고 수치가 바뀌므로 사전 공유 필요.
3. **카세트 열 머리글이 품번으로 바뀜** — 품번 매칭으로 바꾼 결과 총원가·손익계산서의 카세트 열이
   `VINA N_OPPO 하단틀` → `VN034P1` 로 표시된다. 나머지 4개 장표와 통일되지만
   엑셀 '변경 후' 시안은 품명으로 그려져 있다. 품명 표기를 유지해야 하면 별도 표시명 매핑이 필요하다.
4. **`DOI_원장상계` 는 그대로 뒀다** — 여기도 `LEFT(모델, LEN(모델)-1)` 로 무조건 1자를 뗀다.
   `818VT` 가 원장상계에 들어오면 `818V` 로 잘못 붙는다. 이번 지시 범위 밖이라 손대지 않았으나
   같은 `#SALEKEY` 규칙으로 통일할지 확인이 필요하다.
