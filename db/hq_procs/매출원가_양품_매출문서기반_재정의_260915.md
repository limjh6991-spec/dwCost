# 매출원가(제품) 양품(출고)/양품(반품입고) 매출문서 기반 재정의 (2026-09-15, 확정)

대상: 202608 HQ. 매출원가(제품) 화면(C0009007/TAB090007), 결산 손익까지 반영.

## 확정 사양 (담당자 확인 완료)
- **소스**: 세금계산서(국내)=`DOI_SALE_RESC`, 수출신고필증(수출)=`DOI_INVOICE_RESC` (컬럼 품번·수량·판매금액).
- **품번→도우모델 매핑**: **기존과 동일** = `DOI_STOCK.MODEL_TYPE(품번)→MODEL(도우모델)` (818VP→818V, 818VT→818VT, VN034P1→VN034P1, 8195D→8195, 7073P→7073 — 예외 자동 처리).
- **양품(출고)**: 수량 = Σ 매출문서(수량≥0) per 도우모델. 금액 = **총평균단가(기존 = (기초+입고+타계정입고 금액)/(동 수량)) × 양품출고수량**.
- **양품(반품입고)**: 수량 = Σ 매출문서(수량<0) per 도우모델(음수). 금액·항목배분 = **기존과 동일**(현행 반품평가 = DOI_STOCK.RMA_AMT 크레딧, 음수).
- **원가항목(EXPEN_SEL) 구조**: 매출원가(OUT_AMT)는 항목별 분산 저장(모델당 ~50행). 각 항목 OUT_AMT = 항목단가 × 출고수량. 재정의 = 출고수량을 생산수불 → 매출문서 양품출고수량으로 교체, 항목별 재계산(단가 보존).
- **카세트(VN034)·818V**: 예외 없이 동일 산식(매출문서×총평균) 적용(수기와 달라도 신규 정의 채택).
- **매출원가 총액** = 양품출고 + 양품반품입고 + 나머지(RMA품번변경/공정재투입/폐기/연구/기술평가/타계정 등, 현행 생산수불 기반) → **SALE_COST/손익 반영**.
- **EOH** = 잔액(BOH+IN+재투입−매출원가−LOSS).

## 정밀 대사 결과 (2026-09-15 최종) — **표시 분해, 총액 불변**
현재 라이브(dedup+블록C)를 원시행까지 대사한 결과, **현행 매출원가 총액이 이미 사양과 동일**함을 확인:
- 현행 DOI_STCO의 각 모델 OUT_AMT는 이미 `총평균단가 × 매출문서 양품출고수량(qout) − 반품크레딧(RMA_AMT)` 로 계산돼 있음.
  - 반품 크레딧은 이미 각 모델 `MCOM` 행(블록C, ROW_NUMBER rn=1) OUT_AMT에 `−RMA_AMT`로 매몰(예: 902K −72,328,844, 8136 −8,189,468).
  - 나머지 항목행 OUT_AMT는 이미 `항목단가 × qout`(예: 8136 MDAX 2,460,745 = 1,538×1,600).
- 전 모델 `curOUT = qout + qrtn` (생산수불 OUT이 매출문서 net과 동일). 매출문서 매핑 실패 0건, 1:多 0건.
- **결론: 사용자 요청은 넷팅된 OUT을 양품(출고)/양품(반품입고) 두 컬럼으로 "표시 분해"하는 것이며, 매출원가 총액·손익은 불변.**
- 리포트 필터통과 OUT_AMT = 전체 OUT_AMT = 3,833,817,584 (손실 0), 크레딧행 전부 필터통과(제)통신비/FABOUT).

## 구현 (최종)
- `UP_DOI_STOCK_COST` 후처리(fix260915d, 블록C 직후·COMMIT 앞):
  - **OUT_AMT/EOH/매출원가 총액 불변.** 표시컬럼만 채움.
