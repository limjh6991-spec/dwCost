# HQ 202610 공정재투입(RMA R/W) 재공 집계·평가 수정 (2026-11-11)

운영(도우제조원가시스템) 라이브 프로시저 수정. **8176P 양산 공정재투입**(제품→재공 재투입)이
제조원가(재공) 화면 기타입고에 금액으로 집계되도록 + value 보존(제품 출고액=재공 입고액) 정렬.

## 배경
- 8176P 양산 제품이 공정재투입(43개)되어 제품에서 빠지고 재공으로 재투입됨.
- 요구①: 재공 기타입고에 **금액**이 뜨게 (기존 ETC_IN_* 전부 미평가=수량만).
- 요구②: 재공 기타입고 금액 = 제품 공정재투입 금액 (2원 차이 제거, value 보존).

## 변경 3건 (라이브 ALTER, 백업=*_live_261111.sql / 수정후=*_fix261111*.sql)

### 1) UP_DOI_EXPEN_MATL — RMA 조인 교정 (fix261111_rmajoin)

- 원인: DOI_MATL_RESC 제품 투입행 품번이 `8176P`(양산접미)인데 조인이 `8176R`을 찾아 매칭 실패 → ETC_IN_RMA_AMT=0.
- 결과: 8176 재공 ETC_IN_RMA_QTY=43, ETC_IN_RMA_AMT=474,334 집계 (요구① 충족).

### 2) UP_DOI_COST — EOH 조건 교정 (fix261111_eoh)
- 비카세트 EOH CASE 2곳(경비 L336·재료비 L418):
  `(out_qty + bad_qty + transfer_qty = 0 and loss_qty > 0)` → **`... and loss_qty <> 0`**
- 원인: 공정재투입 시 LOSS_MONTH가 **음수**(-83). 구조건 `loss_qty>0`은 FALSE가 되어 RMA1행 EOH가
  ELSE분기 `단가×eoh_qty/2`(=5,283,860)로 과대평가 → 8176 재공 EOH 10,116,641(과대).
- 수정 후: 음수 LOSS도 `boh+in` 분기 → RMA1행 EOH=474,334. 8176 재공 EOH=5,307,115(정상).
- 블라스트 반경(읽기전용 DRY, 운영데이터): **오직 8176 양산만** 변경(delta -4,809,526), 타 모델 불변.

### 3) UP_DOI_STOCK_COST — 재공 재투입금액 = 제품 OUT_REWORK_AMT 정렬 (fix261111_rmareconcile)
- COMMIT 직전(양품반품 크레딧 표시 직후)에 블록 추가:
  재공(DOI_COST RMA1행 [in]/ETC_IN_RMA_AMT/eoh)을 제품(DOI_STCO) `SUM(OUT_REWORK_AMT)`에 모델별 정렬.
- 원인: 재공은 ERP 품목별투입조회 투입금액(474,334), 제품은 가중평균 출고단가×수량(474,336) →
  제품이 재고에서 빼는 금액 ≠ 재공이 받는 금액 = **2원 누수**.
- 정렬 방향: **재공 → 제품(474,336)** (사용자 확정 2026-11-11). RMA1행 boh=0, out=bad=transfer=0 → eoh=boh+in.
- 결과: 제품 OUT_REWORK=재공 ETC_IN_RMA=474,336 (전 모델 diff=0). 8176 재공 EOH 5,307,115→5,307,117(+2).
