# HQ 기타입출고금액 / 면적기준정보 API 호출기능 개발 (2026-09-18)

정의서 `KR_InterFace_정의서_ver1.2.xlsx`의 **HQ 면적기준정보 / 기타입출고금액** 시트 기반.
화면 위치·탭 구조 **무변경**, **API 호출 버튼만** 신설(요청 확정). 두 버튼 **로그인 계정 'SUPERADMIN' 전용** 노출.

## 1) 기타입출고금액 — `ETC_INOUT_HQ` (ERP)
- 엔드포인트: 영림원 `WBS.Ylw.ESM.BSSESMCEtcOutAmt/Query` (VN `ETC_INOUT` 미러, seq 520148/520234, method1, company1, **lang1**).
- 화면: `C0007017.vue`(기타입출고금액, 본사). `apiCallClick` → `ifaceKey('ETC_INOUT')`=`ETC_INOUT_HQ`.
- 흐름: 적재 `DOI_HQ_IF_ETC_INOUT`(`$.DataBlock1`) → 변환 `DOI_ETC_INOUT`(회계단위 상수 '본사', 월필터=일자 앞6). 본 화면(C0007017_Sch1)이 `DOI_ETC_INOUT` 소비.
- ⚠️ 응답 스키마: 정의서 ver1.2 응답표(송장형 InvoiceSeq/Qty/DomAmt…)와 실작동 VN 로더 필드(InOutDate/EtcOutQty…)가 상이. **동일 엔드포인트+동일 원가관리형 요청(SMCostMng/CostYMFr/To)에서 VN이 InOutDate/EtcOutQty 응답을 반환하는 것이 실증됨** → VN 형태로 미러. 실 HQ 호출 응답이 다르면(정의서 송장형) 스테이징/xform 재설계 필요(실호출 1건으로 확정).

## 2) 면적기준정보 — `PRODUCT_SPEC_HQ` (MES)
- 엔드포인트: 미라콤 `GET http://10.100.40.18:9001/api/mes/product-spec?models=<모델>` (models 미지정=전체). 응답 **top-level 배열** `[{area,Model,width,Spec,Prod_code,height}]`.
- 화면: `TAB010004.vue`(원가기준정보 C0001004 > 면적기준정보 탭). `areaApiCallClick` → `PRODUCT_SPEC_HQ`. 기존 VN `ITEM` 버튼·HQ `genData` 버튼은 그대로.
- 흐름: 적재 `DOI_HQ_IF_PRODUCT_SPEC`(`OPENJSON(@json)` 루트배열) → 변환 `DOI_MODEL_MAST[HQ]`: MODEL←Model, X←width, Y←height, XY←area(없으면 width×height 폴백), SPEC←Spec.
- 마감무관(마스터): 백엔드 `skipClosingGuard`로 마감월도 갱신 가능(사용자 확정). 갱신정책: **자동행(ADD_YN='N') 덮어쓰기 + 누락 INSERT, 수동추가행(ADD_YN='Y') 보존**. (운영 DOI_MODEL_MAST[HQ]는 genData로 XY가 이미 채워져 있어 fill-empty면 no-op → 덮어쓰기 채택.)

## 코드 변경 (Java/Vue/yml — jar 재빌드 필요)
- `IfEndpoint.java`: enum `ETC_INOUT_HQ`/`PRODUCT_SPEC_HQ` + `ERP_SEQ.put(ETC_INOUT_HQ,{520148,520234,1,1,1})` + `Trait{MES_QUERY,SKIP_CLOSING_GUARD}`·`FLAGS`·`mesQuery()`/`skipClosingGuard()`.
- `MesApiClient.java`: `baseUrlFor(site)` + `mesQuery()` GET/query-string 분기 + `buildQueryString`(site 제외·컬렉션 전개).
- `IfProperties.java`: `Mes.hqBaseUrl` + `baseUrlFor(site)`.
- `IfServiceImpl.java`: 마감가드에 `!ep.skipClosingGuard()` 선행 + status() hqBaseUrl 노출.
- `application.yml`/`application-dev.yml`: `iface.mes.hq-base-url=${IFACE_MES_HQ_BASE_URL:http://10.100.40.18:9001}`.
- `C0007017.vue`: ifaceApiMixin+siteMap+`canCallIfApi`(userInfo.userId==='SUPERADMIN')+`apiCallClick`.
- `TAB010004.vue`: `canAreaApi`(동일 게이트)+`areaApiCallClick`.
  - ★게이트는 **역할(roleList) 아님, 로그인 계정 userInfo.userId** (SUPERADMIN은 USER_ID). roleList.includes('SUPERADMIN')는 과거 '아무에게도 안보임'으로 제거된 오패턴(9f9b149c) — 재발 방지.

## DB 개체 (SSMS 수동 — 개발 DWCMSTEST → 운영 도우제조원가시스템)
1. `DOI_HQ_IF_staging_260918.sql` (스테이징 `DOI_HQ_IF_ETC_INOUT`, `DOI_HQ_IF_PRODUCT_SPEC`)
2. `UP_HQ_IF_LOAD_ETC_INOUT.sql`, `UP_HQ_IF_XFORM_ETC_INOUT.sql`
3. `UP_HQ_IF_LOAD_PRODUCT_SPEC.sql`, `UP_HQ_IF_XFORM_PRODUCT_SPEC.sql`
- 운영 목적지 `DOI_ETC_INOUT`·`DOI_MODEL_MAST`는 이미 존재. 신규는 HQ 인터페이스 3+2 개체뿐.

## 검증
- Java 컴파일 exit0. SQL TX 스모크(DWCMSTEST, 롤백): ETC 적재→DOI_ETC_INOUT 매핑 정상, PRODUCT_SPEC 적재→DOI_MODEL_MAST INSERT/UPDATE 멱등(재실행 중복0). 적대적 리뷰 4차원→확정결함 전량 반영.
- ⚠️ 실 HQ ERP/MES 호출은 cert/서버도달 후 실데이터 1건으로 필드매핑 최종 대사 필요(특히 ETC 응답형·MES models 파라미터/전체조회 동작).

## 배포 유의
- 운영 프로파일에 `iface.mes.hq-base-url` env(`IFACE_MES_HQ_BASE_URL`) 확인(기본값=TEST 9001, erp.hq-base-url과 동일 관례).
- 프론트 소스만 커밋 → 팀 'rebuild dev jar'가 public/청크+jar 재생성. DB는 SSMS 수동.
