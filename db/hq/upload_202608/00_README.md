## 배경

202608 운영DB에는 이미 **API(영림원 ERP) 적재분**이 들어 있었다. 8월 엑셀과 테이블별로 대사한
결과 **9개 테이블 전부 불일치**로 확인되어, 각 테이블의 202608 데이터를 지우고 엑셀로 교체한다.

가장 중요한 차이는 `DOI_DEPT_COST`다. API 적재분(570행)은 **ERP 원천 코스트센터**(전사·총무그룹·
구매그룹·인사그룹)이고, 엑셀(652행)은 결산담당자가 **제조공통 / 판매공통 / 카세트양산배부공통으로
재배부한 확정본**이다. GL 계정 단위 합계는 148개 계정 전부 차이 0이지만, 코스트센터 귀속이 달라
**생산간접 차변 617,875,230원이 API에서는 판매간접으로 앉아 있다.** 부서기준 배부(UP_DOI_EXPEN_MATL)는
코스트센터 그레인을 그대로 쓰므로 API 상태로 결산하면 제품별 제조경비가 틀어진다.

실행 시점에 202608은 **미마감**이고 결산 산출물(doi_acct_expen / DOI_EXPEN_MATL / doi_mat_cost /
DOI_COST / doi_smce_cost)이 전부 0행이었다. 즉 무효화될 하위 데이터가 없는 상태다.

## 주의사항

**화면 업로드를 쓰지 말 것.** `C0007005_InsertExcel1`(매출)은 거래명세서번호 NOT EXISTS로 중복을
거르는데 61건이 이미 DB에 있어 **조용히 0행 삽입**된다. `InsertExcel2`(수출)는 Invoice관리번호로
거르는데 DB값('DWV-260820-001')과 엑셀값('202608200001')이 서로 달라 **7행이 추가되어 수출매출이
2배(1,043,787,944 → 2,087,575,888)가 된다.** 반드시 이 스크립트로 교체할 것.

**8월 엑셀에서 바뀐 것 두 가지.**
- 재공품수불(`재고금액` 시트)에 **`기타출고(폐기)` 컬럼이 신규 추가**됐다. 7월 기준으로 열 위치를
  하드코딩한 로더를 그대로 돌리면 그 오른쪽 전체가 한 칸씩 밀린다. 06번은 헤더 라벨 기준으로 매핑했다.
- 유상사급 상계의 **원장사용량(F열)이 미정수화 분수값**(31.625 등)으로 들어왔다. 202606/202607
  선례대로 FLOOR를 적용했다(음수도 내림 — 0방향 절사와 다르다).

**창고수불 '이동처리' 열.** 7월엔 제품에 값이 0이라 드러나지 않았으나 8월에 464건 발생했다.
20열(입고)·32열(출고)을 각각 MOVING에 합산해야 입고 항등식이 맞는다. 07번에 반영했다.

**출고 항등식 2행 불일치는 엑셀 자체 모순.** 7073P·7110P가 '기타출고 71/97인데 출고수량 0'이다.
나머지 110행은 차이 0이다. 검증에는 입고 항등식만 넣었다.
